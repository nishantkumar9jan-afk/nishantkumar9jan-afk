Aapka personal GitHub Profile README setup karne ke liye niche diye gaye aasan steps follow karein:

## 📌 Step 1: Special GitHub Repository Banayein
1. **GitHub** par login karein: [https://github.com/new](https://github.com/new)
2. **Repository Name** me likhein: `nishantkumar9jan-afk`
   - GitHub ek green banner dikhayega:
     > *"You found a secret! `nishantkumar9jan-afk/nishantkumar9jan-afk` is a special repository that you can use to add a README.md to your GitHub profile."*
3. Repository ko **Public** select karein.
4. **"Add a README file"** checkbox ko check karein.
5. **Create repository** par click karein.

## 📌 Step 2: `README.md` File Update Karein
1. Apne naye bane repo me jayein: `https://github.com/nishantkumar9jan-afk/nishantkumar9jan-afk`
2. `README.md` ke edit button (pencil icon ✏️) par click karein.
3. Is folder ke [README.md](file:///C:/Users/NISHANT%20GUPTA/.gemini/antigravity/scratch/github-profile-readme/README.md) ka saara content copy karke wahan paste kar dein.
4. Neeche **Commit changes** button par click karein.

---

## 📌 Step 3: Contribution Snake Workflow Add Karein (Optional but Recommended)
Snake animation ko enable karne ke liye:
1. Apne repo me **Add file** -> **Create new file** par click karein.
2. File path me likhein: `.github/workflows/snake.yml`
3. Is folder ke [.github/workflows/snake.yml](file:///C:/Users/NISHANT%20GUPTA/.gemini/antigravity/scratch/github-profile-readme/.github/workflows/snake.yml) ka code paste kar dein.
4. **Commit changes** karein.
5. Ab repo ke **Settings** -> **Actions** -> **General** me jayein:
   - Scroll down to **Workflow permissions**
   - **"Read and write permissions"** select karein aur **Save** karein.
6. **Actions** tab par jakar `Generate GitHub Contribution Snake` workflow ko ek baar **Run workflow** kar dein.
